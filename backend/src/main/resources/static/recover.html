Enrolment

Lost every certificate?

Completing a recovery revokes all your current certificates, closes every session and sends you a notification. If you still have another enrolled device, sign in with it and revoke only the lost one instead.

First generate a new key pair locally:

openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:P-256 -out key.pem
openssl req -new -key key.pem -subj /CN=csr -out csr.pem

Option A - backup code

Option B - e-mail link
