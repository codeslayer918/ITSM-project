Add a second device (backup method)

On the other device: openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:P-256 -out key.pem then openssl req -new -key key.pem -subj /CN=csr -out csr.pem, and paste csr.pem here. The private key never leaves that device.

Backup codes

10 one-time codes, stored hashed (Argon2id). They can only enrol a new certificate if every device is lost; they never log you in. Regenerating invalidates the previous codes.
